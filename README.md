## 🚀 Key Features

* **🎨 4K HD Portrait Wallpapers:** Optimized at 1080x1440 for high-end mobile displays and Instagram formats.
* **📖 Authentic Bhagavad Gita Shlokas:** Every darshan is paired with an authentic Sanskrit shloka and deep Hindi contemplation.
* **⚡ Multi-Channel Cloud Broadcast:** Automated cross-platform publishing engine integrating Meta Graph API (Threads, Instagram, Facebook), Telegram Bot API, and Pinterest API v5.
* **🌐 Web Push Darshan Notifications:** Native browser push notifications powered by OneSignal to alert devotees of morning and evening shlokas.
* **🔒 Enterprise Security & Sanitization:** Strict frame security, XSS sanitization, anti-spam heuristics, and client-side comment moderation.
